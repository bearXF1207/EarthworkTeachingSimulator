## 核心设计说明

- 工具状态是判别联合，每种工具只保留自己的临时数据；切换工具、`Esc`、取消都会清空上一工具草稿。草稿不进入 `Project.elements`、历史或文件，只有成功完成/放置才派发一次 `add` 命令。
- 投影使用画布自身 bounding rect（不是窗口宽高）；越界与零尺寸直接返回 null。视线与地面接近平行时（`|n·d| < 1e-9`）交点会漂移到远处，同样按无交点处理，并与“只有俯视用于地面绘制”的视角判断形成双重保护。
- 双击分三层处理：忽略 `detail > 1` 的 click；忽略与末节点重合的位置；`dblclick`、`Enter` 与“完成基槽”按钮共用同一个 `finishTrench` 校验提交函数，不依赖最终校验去兜底重复点或生成半个对象。
- 拖动判定：`pointerdown` 与 `click` 之间位移超过 3 CSS 像素即按平移处理，因此绘制期间的平移与缩放不会落点。
- 精确输入按绝对方位角推算 `q = (p.x + L·cosθ, p.y + L·sinθ)`，θ 正规化到 `[0,360)`，结果**不做吸附**，长度不会被改写；鼠标点先投影到地面再按每轴 `Math.round(v/1)*1` 吸附，结果归一化 `-0`。
- 快捷键保护：`input/textarea/select/contenteditable` 以及 `isComposing`/`keyCode 229` 都不触发场景命令；输入框内 `Enter` 只提交输入段，`Esc` 不取消草稿，`Ctrl+Z` 仍归文本编辑。
- 预览与提交同源：预览折线来自同一草稿状态，基坑预览由 `pitFromDraft` + 槽顶轮廓生成，与提交使用同一个构造函数，避免预览与结果字段不一致。
- 进入绘制/放置工具自动切到俯视并锁定视角按钮，取消或完成后恢复进入前的视角；选中新对象，预览资源立即清空。

### 设计说明

- 吸附目标按类型提供：`node`（中心线节点，端点对接）、`centerline`（中心线线段，对齐与 T 形参考）、`flush-line`（槽顶边界向外平移**新槽顶半宽** `T=B/2+H·m` 后的贴合线，边对边贴合）、`boundary-corner`/`boundary-edge`（槽顶边界角点与边）。默认半径 1.5m。
- 选择规则：先取最近目标，距离并列时按类型优先（节点 > 中心线 > 贴合线 > 边界角点 > 边界边）；端点与角点带 0.4m 等效距离优惠，避免端面边界边压过端点本身。没有目标时回退 1m 网格；关闭吸附时完全不吸附。
- 贴合线是“边对边贴合”的关键：中心线落在 `边界 + T` 上时，新槽的槽顶边界正好与相邻基槽共线，因此只共边不交叠，可直接被校验接受。
- 正交模式：只约束鼠标绘制，按相对上一节点的位移取水平或竖直（相等取水平），锁定的轴不再吸附、网格兜底也只吸附自由坐标；长度/角度精确输入仍按输入值，不静默改写用户角度。
- 闭合连接采用的模型：基槽之间只允许**边界接触**（共边、共点、端面贴合），内部交叠仍拒绝。四段围合时每个转角只归一段所有（例如底段贯通两个下角、右段贯通右上角），即可用只共边的方式围成完整封闭区域；被围合的岛仍是地面。
- 允许接触后地面三角化仍然成立：共边孔洞的总面积等于各孔面积之和，earcut 给出的实际面积与期望值差值在 `1e-6m²` 以内，孔内无覆盖、岛被覆盖、网格只裁剪槽内区间。无需引入布尔运算或 CSG（与设计约定一致）。

### 边界与取舍

- 转角相接与 T 形分叉需要把相邻槽的交叠部分做并集（实体 CSG），本期不做：转角请并入同一条折线基槽，分叉会被拒绝并提示。因此“围合成封闭区域”需要在四个转角上按“一角归一段”的方式布置（贴合线与角点吸附会引导到位），此时各段只共边，视觉上完全闭合。
- 共边/围合属于 earcut 的退化输入：四段围合时岛内可能出现零面积级的重复三角形（总面积校验通过、可见结果正确）。彻底消除需要自写并集三角化，列入后续优化。
- 正交模式只作用于鼠标绘制；长度/角度输入保持显式角度（沿用“精确输入不吸附”的既有约定）。
- 吸附是固定 1.5m 地面半径，不随缩放变化；吸附目标只取相邻**基槽**，不含基坑。
- 边界边吸附本身会让中心线压在相邻槽边界上而形成交叠，会被校验拒绝并给出指引；实际贴边请使用贴合线（自适应新槽顶半宽）。
