# M7 土方量、结果显示与两点距离测量

M0–M6 已完成基础场景、三类基坑、折线/环形基槽、俯视绘制与吸附贯通、画布点选与拖动编辑。M7 补齐"算出来并展示"的能力：解析土方量、工程量读数与两点距离测量。

## 本阶段交付

- **计算层 `src/core/calculation/`（纯函数，不依赖 Three/React/格式化）**：
  - `measurement.ts`：两点平面距离 `distance`、折线总长 `polylineLength`；非有限输入与点数不足返回 `null`，不返回 `NaN`。闭合中心线末点等于首点，闭合段自然计入总长。
  - `trenchVolume.ts`：`T = B + 2Hm`、`A = (B + T)H / 2 = BH + mH²`、`V = A·ΣL`；另有 `trenchTopWidth`、`trenchSectionArea`。
  - `pitVolume.ts`：方形/矩形 `V = LWH + m(L+W)H² + (4/3)m²H³`（方形取 `L=W`）；圆形 `V = πH(R²+Rr+r²)/3`，`r = D/2`、`R = r + mH`；另有顶/底尺寸与底面积。
  - `quantities.ts`：`quantityOf(element)` 给出带单位的读数行与体积，`totalVolume(elements)` 只对可计算的对象求和。
- **结果显示**：属性面板下方新增 `QuantityView`，展示类型工程量（基槽：中心线长度/底宽/顶宽/断面面积；基坑：底部与顶部尺寸/底面积）与**预计土方量**；侧栏底部新增"工程量合计"区域。读数统一两位小数，计算层保留完整精度，四舍五入不回写参数。
- **两点距离测量**：工具按钮"测量"启用。俯视下单击设第一点、再单击设第二点；画布上显示连线与跟随当前点的距离标签，面板同步显示"测量距离"；再点一次即从该点重新测量，"重新测量"按钮或 `Esc` 取消。测量结果只存在于草稿状态机，不进入工程数据、命令历史或文件。
- **阶段标记**：页眉 `M7 · 土方量`；侧栏说明同步为 M7 范围。

## 关键设计

| 关注点 | 做法 |
| --- | --- |
| 计算与显示分离 | `core/calculation` 只返回有限数值或 `null`；格式化只发生在 `QuantityView`/面板 |
| 公式与几何一致 | 基槽按整槽统一截面沿中心线拉伸；基坑按坑型分别解析，不对低精度 Mesh 三角形求和 |
| 矩形不用相似截面公式 | 等水平外扩的非正方形矩形上下截面不相似，`H/3(A底+A顶+√(A底·A顶))` 不适用（已作为回归用例） |
| 范围为教学估算 | 折线转角处不单独累加/扣减边坡重叠体积；结果标记"预计土方量"，不宣称工程计价精度 |
| 临时测量不落盘 | 测量走 `DrawingManager` 草稿分支，切换工具/Esc/重新测量即清空，不产生任何命令 |
| 合计口径 | 只对已通过校验并进入工程的元素求和，草稿与测量不计入，不合并相交开挖 |

## 验证

`npm run check` 全绿：**11 文件 174 项测试**（新增 `tests/calculation.test.ts` 20 项 + 界面用例 4 项）。

数值用例（与手册 §9 一一对应）：

- 直槽 `L=20/B=2/H=2/m=.5`：`T=4`、`A=6`、`V=120m³`；L 型 `(0,0),(10,0),(10,10)` 同样 `V=120m³`。
- 多段 `(0,0),(10,0),(15,5),(25,5)`：`V=6×(20+√50)≈162.4264068712m³`。
- 原需求展示例 `L=25.6/B=2/H=1.5/m=.5`：顶宽 `3.5`，`V=105.6m³`。
- 环形基槽：`A=6`、闭合中心线 `80m`、`V=480m³`（与 M5 环形几何的网格体积一致）。
- 方坑 `4×4/H=2/m=.5`：`152/3≈50.6667m³`；矩形 `6×4`：`212/3≈70.6667m³`；圆坑直径 `4`：`38π/3≈39.7935m³`。
- `m=0` 退化为棱柱/圆柱；各方向放大 2 倍体积为 8 倍；矩形错误棱台公式与本设计公式的差值 >0.01（防回归）。
- 独立几何交叉验证：对开挖实体三角面做有向四面体积分（顶部开口在 `z=0`，补盖贡献为 0），方/矩形与解析值相对差 <1e-6，96 段圆坑 <0.1%。
- 测量：`(0,0)→(3,4)` 为 `5m`；同点 `0m`；平移/旋转同一批点集长度不变；非有限输入返回 `null`。

真实浏览器验收（真实鼠标与键盘）：

- 绘制 20m 基槽并回车确认 → 面板显示"中心线长度 20.00 m / 顶宽 T 4.00 m / 断面面积 A 6.00 m² / 预计土方量 120.00 m³"，合计 `120.00 m³`。
- 放置默认方形基坑 → "底部 4.00×4.00 / 顶部 6.00×6.00 / 底面积 16.00 m² / 50.67 m³"，合计 `170.67 m³`。
- 编辑深度为 4 → `T=6.00`、`A=16.00`、`320.00 m³`；坡比改为 0 → `T=2.00`（等于底宽）、`A=8.00`、`160.00 m³`。
- 测量工具：单击 `(10,10)` 与 `(13,14)` → 面板与画布标签均为 `5.00 m`；"重新测量"后测 `(0,0)→(0,30)` 得 `30.00 m`；`Esc` 后标签与提示清除，对象数仍为 2，全程无 window error/console.error。

## 已知取舍与后续

- 折线基槽的转角体积按 `A·ΣL` 估算：转角处边坡重叠既不单独累加也不扣减，与网格几何会有小量差异（直槽差异 <1e-6 相对量）。
- 圆坑显示与地面开孔仍用 96 边形，其网格体积比解析值小约 0.07%（在 0.1% 内）。
- 测量只做地面 XY 两点距离：不提供角度、高差或面积测量；标签为画布叠加层，不随相机缩放改变字号。
- 保存/打开、撤销重做属 M8；工程量目前不导出、不参与文件 schema。
