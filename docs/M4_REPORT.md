## 核心设计说明

- 转角求解：`turn=atan2(cross(d0,d1),dot(d0,d1))`，`j=normalize(n0+n1)`、`denom=dot(j,n1)`，偏移点取 `p±j·w/denom`。`1/denom` 就是 miter 长与半宽之比、也等于 `1/cos(|turn|/2)`：`denom≤0`（折返）或比值超过 4（约 151° 以上转向）直接拒绝，并给出转向角与比值。左右转共用同一公式，镜像布置天然对称。
- 一条连续边界而不是多段拼装：底、顶各用一个闭合环（左侧正序 + 右侧倒序），内部转角共享同一 miter 决策，端点用所属段法向形成垂直端面。两个环用同一次绕序决策统一到逆时针并保持节点一一对应，所以侧面三角形数量恒定、转角处不会出现接缝或重叠面。
- 轮廓与中心线是两层校验：先查节点（数量、有限、范围）、逐段长度、非相邻段的相交/接触/共线重叠、重复节点；再生成底/顶环并检查简单多边形（零长边、面积塌缩、自交、共线回折），坡比大于零时还要求顶环完整包住底环。任何失败都转成 `elements[i].points[k]` 形式的中文 issue，不静默删节点、不截短、不自动改坡比。
- 中心线合法不代表偏移合法：窄 U 形（`(0,0),(10,0),(10,1),(0,1)`）中心线本身无自交，但槽底/槽顶环自相交，必须按偏移失效拒绝，这是 M3 只有两个节点时不会出现的情况。
- 槽底可能是凹多边形（折线转角处），因此三角化换成支持凹多边形与共线顶点的实现，并按绕序统一、过滤零面积三角形；共线中间节点保留在数据里但不产生退化面。
- 改写槽底三角化时一度按“三角形数”划分材质组，非索引几何的组边界其实是顶点序号，M2 的射线回归立刻命中错位三角形；改回顶点数后恢复，说明既有回归确实在守边界。

## 真实浏览器验收

在开发服务、真实 WebGL 画布中把折线槽依次设为手册用例：

1. 90° L 型：俯视槽口为 L 形带、网格在开口处停止；自由视角可见内侧凹角与外侧凸角连续，无裂缝、尖刺或错位面。
2. 45°（`(0,0),(10,0),(15,5)`）与钝角 60°（`(0,0),(10,0),(15,8.6602540378)`）：转角内外侧过渡平滑，地面孔洞与槽顶边界一致。
3. 线框模式：转角处只有一次对角线剖分，没有跨臂连线或跨开口的错线。
4. 超出 miter 上限：编辑成 160° 量级转角后模型保持上一有效状态，属性面板显示“`elements[0].points[1]：节点转角 156.9° 的 miter 比 5.00 超出上限 4，请减小坡比或放宽转角`”；取消并重新选中对象可确认模型节点没有被改写。
5. 折返（把终点 Y 改回与起点同高）：同样被拒绝并保留旧模型。
6. 折线基槽、直线基槽与方形基坑共存（3 个开挖对象），对象列表分别显示“折线基槽/直线基槽/方形基坑”；全程 `window` error、unhandledrejection 与 `console.error` 为空。

## 已知边界

- 仍无绘制交互：点击落点、预览线、吸附与 Enter/Esc 属 M5；界面只能编辑已有节点，节点增删只能在数据层进行。
- 不支持圆弧、样条、分段不同参数与 bevel 回退；折返与超限转角一律拒绝，不做自动倒角或自动截短。
- 轮廓与中心线检查是 O(n²)（两两线段相交、点在环内），200 节点量级可接受；大量开挖对象且每个都接近上限时的重复计算仍是后续性能关注点。
- `V=A·ΣL` 对批准的折线规则是教学估算，角部重叠扣减不做布尔运算，与 M2 起的总体积口径一致。
- 未改动的 M2 遗留项：`PROJECT_SPEC.txt` 删除与 `PROJECT_SPEC.md` 未跟踪状态保持原样，不纳入提交。
