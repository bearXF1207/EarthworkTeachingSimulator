## 核心设计说明

- 直线基槽由两个节点和统一 `bottomWidth/depth/slope` 定义：`d=(p1-p0)/L`、`n=(-d.y,d.x)`，端点断面用 `p±n*b` 与 `p±n*t` 生成，`z=-H` 与 `z=0`。
- 端面垂直、不沿 `d` 扩展，因此顶/底长度都等于中心线长度，为 M7 的 `V=(B+T)/2·H·L` 提供精确前提。
- 共用 `buildRingSolid`：底面按轮廓扇形三角化，侧面按“对应边两个三角形”成环。基槽的两个长边自然成为边坡、两个短边自然成为垂直端面，因此没有第二套绕序实现，也不需要在生成器里分类型铺面。
- 顶部开口与几何同源（同一份 `topOutline`），地面带孔三角化与 1m 网格裁剪直接复用 M2 机制，孔洞与槽顶边界严丝合缝。
- 开口冲突统一为“逆时针轮廓 + 可选解析圆”：圆坑保留解析顶半径（不漏内接弦之外的细小重叠），基槽–基坑、基槽–基槽走同一套“点在多边形内 / 边段相交 / 相切”判定，新增元素类型不需要再写碰撞分支。
- 仍然先完整校验候选，再生成候选资源，最后同步 commit；失败不进入 `prepare`，不修改快照、场景与选择。

## 已知边界

- 仍是演示入口，没有鼠标绘制、网格吸附、测量与保存/撤销；折线基槽、节点拖动属于 M4/M5/M6。
- 自由/正交视角放大依赖滚轮，远端对象不会自动入镜（沿用 M2 行为）。
- 每次合法参数变化重建全部对象与地面；本阶段以 70 项测试和上述小规模浏览器操作验收，不构成 500 对象性能承诺。
- 演示入口在候选被拒绝时也会占用一个序号（例如跳过 `pit-1`），只影响后续演示对象的 id 与默认位置，不影响校验与几何。
- `scripts/smoke.mjs` 原先依赖 vite 的 `close()` 及时完成；在 Windows 上它会偶发不 settle。本次改为有限等待、超时强制断开连接并记录警告，最后在校验全部通过后显式退出；断言失败仍以非零码结束（已用故意失败的副本验证）。
- `PROJECT_SPEC.md`（未跟踪）与 `PROJECT_SPEC.txt`（已删除）是当时的既有状态，本次保持原样且不纳入提交（2026-09-23 工程整理：`PROJECT_SPEC.md` 纳入版本库并取代 `PROJECT_SPEC.txt`）。
